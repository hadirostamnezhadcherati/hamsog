# همسوگ - نسخه آنلاین نهایی

این نسخه برای اجرا به‌صورت آنلاین آماده شده است: صفحه مشتری، پنل مدیریت، ذخیره درخواست‌ها، تماس مستقیم، پیامک پیش‌فرض، خروجی CSV و نصب روی موبایل به‌صورت PWA.

## اجرای سریع روی ویندوز

داخل پوشه `hamsog`، CMD را باز کنید و بزنید:

```cmd
npm install
node server.js
```

صفحه مشتری:

```text
http://localhost:3000
```

پنل مدیریت:

```text
http://localhost:3000/admin-v4.html
```

ورود پیش‌فرض محلی:

```text
نام کاربری: admin
رمز عبور: admin123
```

## نکته مهم امنیتی برای آنلاین کردن

قبل از انتشار عمومی، رمز مدیر را تغییر بدهید. روی سرور این متغیرها را تنظیم کنید:

```text
ADMIN_USERNAME=admin
ADMIN_PASSWORD=یک رمز قوی
ADMIN_TOKEN=یک متن طولانی و تصادفی
```

نمونه داخل فایل `.env.example` آمده است.

## نصب روی موبایل

بعد از آنلاین شدن روی دامنه HTTPS، کاربر با Chrome موبایل آدرس سایت را باز می‌کند و از منوی سه‌نقطه گزینه زیر را می‌زند:

```text
Install app / Add to Home screen
```

آیکون جدید برنامه: دست سبز ملایم در حال رسیدن به نور امید.

## آنلاین کردن روی Render

1. یک حساب Render بسازید.
2. پروژه را در GitHub بگذارید.
3. در Render گزینه New Web Service را بزنید.
4. مخزن پروژه را انتخاب کنید.
5. Build Command: `npm install`
6. Start Command: `npm start`
7. Environment Variables را تنظیم کنید: `ADMIN_USERNAME`, `ADMIN_PASSWORD`, `ADMIN_TOKEN`, `DATA_DIR`.

بعد از Deploy، آدرس عمومی سایت را دارید. صفحه مشتری روی ریشه دامنه است و پنل مدیریت با `/admin-v4.html` باز می‌شود.

## مسیر کاری فروش

مشتری فرم را ثبت می‌کند، درخواست در پنل دیده می‌شود، مدیر با دکمه تماس مستقیم تماس می‌گیرد، سپس پیامک پیش‌فرض شماره کارت و مبلغ را ارسال می‌کند و وضعیت پیگیری را ثبت می‌کند.
